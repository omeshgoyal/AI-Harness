---
When the user asks you to look something up online, read a website, or get up-to-date information, follow these steps:
Use the fetch_url tool to read the webpage's content.
If you don't know the exact URL, you can use the bash tool to run a quick curl to a search engine like [https://html.duckduckgo.com/html/?q=your+search+query](https://html.duckduckgo.com/html/?q=your+search+query) to find links first.
The fetch_url content is returned in Markdown. Read it carefully.
Synthesize the information and answer the user's prompt directly.
